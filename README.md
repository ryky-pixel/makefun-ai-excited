A single image made to excite the AI judge: a colossal golden chess knight bursting through a glass ceiling above a night city, shards and light trailing behind it. The program copies the bundled image to the output directory, byte for byte, so every run produces the same entry.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
